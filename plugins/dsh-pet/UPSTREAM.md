This directory is an unmodified copy of the published `dsh-pet@0.3.8`
package contents (the package already ships the built `lib/` plus `src/`,
`assets/` and the Electron helper runtime), kept here so the collection has a
pinned, locally installable copy. Upstream is the source of truth for code
changes and releases; send fixes there first.

Install from this checkout:

```sh
dsh plugin --profile desktop add /absolute/path/to/deepseek-harness-plugins/plugins/dsh-pet
```

or install the published package with `dsh plugin --profile desktop add dsh-pet`.
