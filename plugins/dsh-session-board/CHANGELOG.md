# Changelog

## 0.2.1 — 2026-10-18

- 修正版本发布管理：插件清单、界面版本标识、安装包名和 Git 标签统一到 0.2.1，避免不同产物继续复用 0.2.0。
- 界面版本标识移除历史 `-review` 后缀。
- 延续此前本地迭代成果：搜索筛选、简洁卡片、触控板滚动、工作区树、Wiki 归档提炼及 DSH 原生归档状态同步。
- 功能与首个公开 0.2.0 基本相同，本版本主要用于明确区分历史同版本构建；不宣称新增已经发布的功能。

## 0.2.0 — 2026-10-18

首个公开版本，汇总此前多次同版本本地迭代：

- 贴边会话栏和全屏看板，状态、工作区、工作区路径树分组。
- 搜索、状态与工作区筛选，简洁卡片及详情展开。
- 修复卡片区域阻断触控板滚动的问题。
- 精确主/子会话 Wiki 归档、脱敏复核、逐会话提炼与索引更新。
- 本地 Wiki 完成标记、归档可见性筛选，以及 DSH 客户端归档状态同步。

## 版本约定

每次发布变更使用新的版本号；已发布的标签和安装包不覆盖。兼容性修复递增补丁版本，新增功能递增次版本，不兼容变更显式记录。每个插件独立发布，标签格式为 `<插件名>-v<版本>`。
