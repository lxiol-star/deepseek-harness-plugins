# Changelog

## 0.2.6 — 2026-10-19

- 提炼 provider 可由用户文件 `~/.dsh-session-board.json` 的 `synthesisProvider` 指定，发布包不含任何账号相关的默认值。
- 未配置时仍回退到 Wiki 技能默认的 `stepx-terra`；非法值或损坏文件静默回退，不会把任意字符串传给脚本。


## 0.2.5 — 2026-10-19

- 修复正式版 DeepSeek Harness 中归档一律报“本地归档脚本不可用或超时”的问题：应用由 Finder 启动时进程环境没有 `DSH_HOME`，旧实现因此直接判定找不到 home。
- home 解析改为与 DSH 一致的规则：显式配置 → `$DSH_HOME` → `~/.dsh`；Dev 应用设置了 `DSH_HOME` 时仍指向自己的 home，不受影响。
- 新增两条回归测试，覆盖无 `DSH_HOME` 的 GUI 启动路径。


## 0.2.4 — 2026-10-19

- 看板只展示 DSH 工作区实际列出的会话：空白草稿仅在它是当前打开的会话时出现，未归入任何工作区的会话不再显示为卡片。
- 与 DSH 侧栏的可见范围保持一致，避免“看板有、侧栏没有”的对不上。
- 无工作区快照时退回原行为，仅保留空白草稿规则。


## 0.2.3 — 2026-10-19

- 空会话卡片使用独立的空状态样式（斜体、次要色、虚线圆点占位），不再与摘要正文同款排版。
- 完全没有内容的卡片不再显示“展开详情”，避免点了没有任何内容。
- 文案区分“暂无摘要”（有内容但还没生成预览）与“此会话还没有任何内容”。

## 0.2.2 — 2026-10-19

- **修正归档语义**：归档并提炼成功后，插件会调用 DSH 原生归档，把会话移出客户端工作区；此前只写 Wiki 和本地标记，客户端里仍显示为未归档。
- 空会话（无可归档正文）跳过提炼后同样归档，并明确标注“空会话，已归档”。
- 仍在运行、有后台任务、等待你处理，或在确认后又收到新内容的会话不会被归档，保留在工作区并说明原因。
- Wiki 提炼失败、内容含敏感信息或索引更新失败时，不归档到 DSH，保持可见以便重试。
- 批次结果新增“DSH 客户端归档结果”，与 Wiki 原文/知识页结果分开显示。
- 归档可见性筛选同时覆盖 DSH 原生归档与 Wiki 完成标记。

## 0.2.1 — 2026-10-18

- 修正版本发布管理：插件清单、界面版本标识、安装包名和 Git 标签统一到 0.2.1，避免不同产物继续复用 0.2.0。
- 界面版本标识移除历史 `-review` 后缀。
- 延续此前本地迭代成果：搜索筛选、简洁卡片、触控板滚动、工作区树、Wiki 归档提炼及 DSH 原生归档状态同步。
- 功能与首个公开 0.2.0 基本相同，本版本主要用于明确区分历史同版本构建；不宣称新增已经发布的功能。

## 0.2.0 — 2026-10-18

首个公开版本，汇总此前多次同版本本地迭代：

- 贴边会话栏和全屏看板，状态、工作区、工作区路径树分组。
- 搜索、状态与工作区筛选，简洁卡片及详情展开。
- 修复卡片区域阻断触控板滚动的问题。
- 精确主/子会话 Wiki 归档、脱敏复核、逐会话提炼与索引更新。
- 本地 Wiki 完成标记、归档可见性筛选，以及 DSH 客户端归档状态同步。

## 版本约定

每次发布变更使用新的版本号；已发布的标签和安装包不覆盖。兼容性修复递增补丁版本，新增功能递增次版本，不兼容变更显式记录。每个插件独立发布，标签格式为 `<插件名>-v<版本>`。
