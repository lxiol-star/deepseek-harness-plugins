## 0.2.1 — 2026-10-23

修复开启 Ultra / 闪电后本轮运行失败：`format v4 message requires a producer-owned source kind`。

- 原因：策略注入把用户消息的 source 写成 `{ kind: "plugin", plugin: "dsh-whale-effort" }`。DSH 的会话格式 v4 要求 source kind 由产出方自己声明，并且明确拒绝退休的 `plugin` 包装（正式版与 Harness Dev2 的 0.2.1-rc.2 都带这条校验），于是注入发生在真实模型轮次时整轮失败。
- 修法：按 v4 的合并扩展约定，把插件的产出方 kind 声明为 `dsh-whale-effort`（`MessageSourceMap` 的 type augmentation），消息 source 改为 `{ kind: "dsh-whale-effort", form: "instructions" }`；不再写入被拒绝的 `plugin` kind。
- Ultra 策略、闪电策略、去重与会话隔离语义均不变；离线测试更新为断言新的 producer kind。
- 之前失败的会话没有落盘坏行（写入在持久化前被拒），修复后重新开 Ultra 即可正常跑。

## 0.2.0 — 2026-10-23

Ultra 档改为**按模型能力自适应**，并修掉浅色主题下 Ultra 标签的对比度问题：

- 新增自适应规则：只有「模型公开至少两个真实档位、且最高档是 `xhigh` 或 `max`」时才在滑条末尾追加 `Ultra`。最高档更低的模型（例如只有 `low`/`medium`/`high`）不再显示 Ultra，滑条只按真实档位分布、刻度随档数重新排布；从支持的模型切到不支持的模型时，会自动清掉该会话遗留的 Ultra 状态（不再注入严格性策略）。
- 判定按最高档 id 归一化（忽略大小写与首尾空白），不依赖模型名或厂商。
- 浅色主题下选中 Ultra 时，刻度行的小 `Ultra` 标签改用主题强调色（原先固定白色，在白底上几乎不可读）。
- 行为不变：Ultra 仍只写真实最高档（MAX）、不产生伪档位；闪电、tok/s、皮肤与设置页不受影响。153 → 157 个离线测试（新增自适应规则用例），严格类型检查与构建通过；已在 Harness Dev2 复验。

## 0.1.2 — 2026-10-23

修掉「推理等级」面板底部偶发的横向滚动条，并消除 Ultra 标签越界：

- 现象：面板底部出现一条横向滚动条（滑条置顶/Ultra 时最明显），源于 Ultra 刻度文字以居中定位伸出轨道 15px、越过内容区 1px；特效层的光晕/拖尾也会在轨道外侧多画几个像素。

- 行为不变：滑条、Ultra、闪电、tok/s 读数、皮肤与设置页均不受影响；离线测试、严格类型检查与构建照旧。已在 Harness Dev2 复验并重拍 README 截图。

## 0.1.1 — 2026-10-23

修复从插件面板返回原生模型菜单时的键盘焦点丢失（0.1.0 的初次修复实测无效）：

- 从「推理等级」面板按 Esc（或面板根节点的 Shift+Tab）后，原生菜单重新出现，但焦点落在 `<body>`：第二次 Esc 无法关闭菜单，只能点击外部。
- 原因：面板打开期间原生菜单的根行会被卸载，0.1.0 记住的旧节点已 `isConnected === false`，焦点回退被跳过。
- 修法：关闭面板后查询仍挂载的原生菜单，按当前语言定位「推理等级」行并交还焦点；一次微任务 + 一次 `requestAnimationFrame` 覆盖两种提交时序。
- 其余行为与 0.1.0 相同；离线测试、严格类型检查与构建不变，安装包重建并重新发布。0.1.0 的缺陷只影响键盘焦点，滑条、Ultra、闪电、tok/s 与皮肤均正常。

## 0.1.0 — 2026-10-23

首个版本：把两个 MIT 社区插件合并成一个 DSH 插件（本仓库 Apache-2.0），并接入本仓库的包结构、构建与发布流程。

### 合并后的完整能力

- 在 DSH 原生模型选择器的「推理等级」入口里提供能量滑条：档位刻度、当前档位名称、拖动吸附、键盘调节；模型列表、搜索、分组与徽标保持原生。
- 鲸鱼娘跑者滑块按钮（八帧动画，拖动加速，减少动态效果时冻结）。
- 三套科幻能量皮肤 `holo` / `chrome` / `fluid`（默认 `fluid`），`fluid` 带粒子流体引擎与最高档星痕；跟随深色/浅色主题。
- Ultra 显示档：在模型真实档位之后追加一格，选中时写入模型真实最高档（MAX）并注入严格性策略；界面停在 Ultra 时实际档位必为 MAX。
- 闪电模式：面板内开关，默认关闭；注入编排策略，关闭时补 OFF 提示。
- 被跟踪会话的子代理 tok/s 实时读数（完整整数、无数据隐藏），以及只读策略 chip（默认折叠，仅在 Host 解析出非空策略时显示）；闪电开关与 tok/s 读数同一行位于滑条下方。
- 中英双语、键盘可操作、减少动态效果支持；设置 → 通用设置提供「推理强度滑块」「鲸鱼娘滑块」「特效皮肤」三项。
- 自定义模型档位指引：图形界面路径优先，高级配置提供按当前文件缩进生成的 YAML、路径/条目位置与可复制给 Agent 的提示词。
- 无网络请求、无遥测；唯一持久化文件 `$DSH_HOME/storages/dsh-whale-effort.json`。

### 本仓库的合并工作

- 合并成一个包 `dsh-whale-effort`：一个原生入口同时提供滑条、能量皮肤、Ultra、闪电与 tok/s，不再需要安装两个插件。
- Host 半边重写为单一鉴权回环通道：`POST /dsh-whale-effort/<endpoint>`（`diagnose` / `store` / `session/state` / `session/update` / `session/policy`），通过 DSH 连接的 `requestRejection` 做 Host/Origin 与浏览器会话校验；只用结构化 interface 描述宿主服务，运行时不 import `@deepseek-ai/*`。
- 统一持久化：`$DSH_HOME/storages/dsh-whale-effort.json`（version 1、最多 40 个最近会话、临时文件 + rename 原子替换、损坏数据归一化不抛错）。
- 策略注入按会话 id 精确过滤、文本去重、先 `next()` 再追加、永不抛错。
- 构建/检查接入本仓库约定：`npm run check`（严格 tsc + 离线 vitest）、`npm run build`（esbuild 生成 `lib/index.js` / `lib/client.js` / `lib/types/`，内联精灵图与 Markdown），`lib/` 提交进仓库。
- 新增中文/英文 README、`UPSTREAM.md`、`THIRD-PARTY.md`、插件 `LICENSE`（Apache-2.0 正文 + MIT 部分说明）。
