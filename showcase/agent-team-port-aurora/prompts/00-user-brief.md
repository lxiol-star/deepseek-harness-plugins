# 00 · 用户简报

## 原始需求

用户发来一张包含文字的截图（1629×144），内容为：

> 请开启智能体团队，现在我希希望你用你的智能体团队协作做一份可自由旋转的符合审美的超高精度微型港口。没有任何token预算上限，包括子代理，智能体团队。请加油吧！！冲冲冲

补充背景：当时会话处于「never ask for approval」策略；用户明确要求**开启 Agent Teams**，并且**不限 token 预算**（包括子代理）。

## 解读与验收标准

这份需求最终被拆成以下可验收的目标：

1. **智能体团队协作**：必须真实使用 durable teammate、共享任务板、分文件所有权，而不是单会话硬写。
2. **可自由旋转**：360° 环绕 + 俯仰 + 缩放 + 惯性；移动端也要能完整看到模型。
3. **符合审美**：不是技术演示，而是一件「博物馆藏品」——统一色板、柔和展厅光、水面反射、模型底座、纸墨黄铜界面。
4. **超高精度**：部件数量与细节层级要能撑住近景（岸桥、船、堆场、老城、灯塔、人物）。
5. **微型港口**：港口题材完整闭环——集装箱码头 + 船队 + 防波堤/灯塔 + 老城/鱼市 + 铁路 + 水面。
6. **无预算约束**：允许长时间、多轮、多智能体打磨；质量优先。
7. **可交付**：离线可双击打开、可交互、可导出明信片、通过浏览器自动验收。
8. **后续归档**：用户随后要求在 GitHub 插件仓库新建目录保存提示词与产物（即本目录）。

## 最终产物的定位

- 作品名：**微港 · Port Aurora**
- 设定：露港海事博物馆 · 壹号馆藏，1:1000 的胡桃木底座港口模型
- 交互：拖拽环视 / 滚轮缩放 / 双击复位 / 自动旋转 / 图解 / 昼·夜 / 明信片
- 技术：Three.js r160（本地化）、全程序化几何与 Canvas 纹理、批量合批、实例化、实时平面反射、自定义水体与后期
- 验收：66 pass / 3 warn / 0 fail；桌面上限 60 fps
